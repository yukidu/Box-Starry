繁星膠囊 Box Starry 隱私權政策

本政策說明繁星膠囊 Box Starry 如何存取、使用、保存、分享與刪除使用者資料，包括透過 Google / YouTube API Services 取得的資料。

我們會處理哪些資料

為提供服務，我們可能處理你的 Starry ID 基本識別資料、Box Starry 影片管理與分享設定，以及你授權後的 YouTube 頻道、影片、縮圖、播放清單等必要資料。YouTube OAuth 長期授權憑證會以加密方式保存。

我們如何使用 Google / YouTube 資料

Box Starry 只會把 Google / YouTube 資料用於你在介面中看得到並主動操作的功能，包括：同步你自己的 YouTube 影片與播放清單、把你選擇的影片上傳到自己的 YouTube、設定你指定的自訂縮圖，以及把新影片加入你明確勾選的 YouTube 播放清單。

Box Starry 不會取得你的 Google 密碼，也不會在未經你操作或同意的情況下，把 Google / YouTube 資料用於與上述功能無關的目的。

影片檔案與儲存方式

你選擇上傳的影片檔案會直接傳送至 YouTube，不會把影片檔案本身保存到 Box Starry 的 Cloudflare 儲存空間。Box Starry 會保存提供功能所需的影片管理資料、分享設定與加密後的 YouTube 授權憑證。

資料分享、販售與廣告

我們不販售 Google / YouTube 使用者資料，也不會把這些資料提供給廣告平台、資料仲介商或用於個人化廣告。除為提供使用者要求的服務所必要的基礎設施處理、資安與防濫用、法律要求，或取得你的明確同意外，我們不會向第三方移轉 Google 使用者資料。

Google API Services User Data Policy

Box Starry 對從 Google APIs 取得之資訊的使用與移轉，遵守 Google API Services User Data Policy，包括其中的 Limited Use requirements（有限使用規範）。

保留、撤銷與刪除

你可以在 Box Starry 的「YouTube 連線」頁隨時解除 YouTube 授權。解除連線時，Box Starry 會刪除本服務保存的 YouTube 授權資料，並嘗試向 Google 撤銷該授權。你也可以使用「刪除我的 Box Starry 資料」刪除 Box Starry 專屬資料。這些操作不會刪除你已經上傳到 YouTube 的原始影片，也不會刪除你的 Starry ID。

你也可以直接在 Google 帳戶的第三方應用程式授權管理頁撤銷 Box Starry 的存取權。

分享控制

Box Starry 可另外建立自己的分享連結，並設定密碼或失效時間。這些分享控制屬於 Box Starry 功能，不等同於 YouTube 原生分享設定。

第三方服務

Box Starry 使用 Google / YouTube API Services 與 Cloudflare 基礎設施。使用 YouTube 功能時，你同時受到 YouTube 服務條款及 Google 相關政策約束。
